# Phase 5 Manual Review Readability Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `Phase5UiFoundation.unity` a readable, warning-free, paged mobile manual-review scene and produce a P4-style MT-001–034 Excel checklist.

**Architecture:** Keep existing Phase 5 runtime contracts and validation-scene controller, but add five mutually exclusive presentation groups controlled by visible page selectors. Scene content remains generated by Editor APIs; canonical TMP population owns all required characters; workbook is generated after the Scene is verified.

**Tech Stack:** Unity 6000.5.5f1, uGUI, TextMeshPro, Input System, NUnit EditMode/PlayMode, deterministic Editor Scene builder.

## Global Constraints

- Target remains mobile iOS and Android; portrait `1080×1920` is primary and landscape remains functional.
- Do not modify `MainCafe` gameplay or production Build Settings.
- Do not hand-edit `.unity`, `.prefab`, or `.asset` YAML.
- Use RED → GREEN for every behavior change.
- Do not push, merge, or remove the worktree.
- Do not commit without a new explicit Studio Owner authorization.
